# Al3mda-posist

# ☕ العمدة - نظام كاشير

نظام نقاط بيع (POS) خفيف وسهل، مبني بـ **HTML/CSS/JS** و **Supabase**.

## ✨ الميزات

- 🛒 **صفحة كاشير** — اختيار المنتجات، السلة، الفاتورة، الضريبة، طريقة الدفع
- 🍔 **إضافات للمنتجات** — مجموعات إضافات مدفوعة ومجانية، إجبارية واختيارية
- 📦 **إدارة المنتجات** — إضافة/تعديل/حذف/تفعيل/تعطيل
- 📁 **إدارة الفئات** — تنظيم المنتجات بفئات مع أيقونات
- 🧩 **إدارة الإضافات** — مجموعات إضافات قابلة لإعادة الاستخدام
- 💰 **تقرير المبيعات** — فلترة بالتاريخ، إحصائيات، تصدير CSV
- ⚙️ **إعدادات** — اسم المتجر، الضريبة، العملة
- 🔐 **تسجيل دخول** — يوزر/باسورد للأدمن
- 📡 **Realtime** — أي تعديل في الإدارة يظهر فوراً في الكاشير

## 🚀 طريقة التشغيل

### 1) إعداد قاعدة البيانات (Supabase)

1. أنشئ مشروع جديد في [supabase.com](https://supabase.com)
2. افتح **SQL Editor**
3. الصق محتوى ملف `database.sql` كاملاً وشغّله
