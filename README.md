# ☕ العمدة - نظام كاشير

نظام نقاط بيع (POS) للمأكولات الخفيفة، مبني بـ HTML/CSS/JS و Supabase.

## ✨ الميزات

- 🛒 صفحة كاشير كاملة
- 🍔 إضافات للمنتجات (مدفوعة ومجانية)
- 📦 إدارة المنتجات والفئات
- 💰 تقرير المبيعات مع فلتر التاريخ
- 🔐 تسجيل دخول للأدمن
- 📡 Realtime: التحديثات فورية

## 🚀 التشغيل

1. أنشئ مشروع في [supabase.com](https://supabase.com)
2. شغّل `database.sql` في SQL Editor
3. عدّل `supabase.js` بمفاتيح مشروعك
4. ارفع الملفات على GitHub Pages
